# SkyPocket — Agent Guide

SkyPocket is a client-side Fabric mod for Hypixel SkyBlock, built for multiple Minecraft versions
from one shared build script. See `README.md` for the feature overview and build commands, and
`docs/DEVELOPMENT.md` for the development workflow.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `FriedLoop/Skypocket-for-hypixel-skyblock`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
